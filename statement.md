# Project Statement: NPC Generator

## Problem Statement
Role-playing games (RPGs), creative writing projects, and game development often require a large variety of Non-Player Characters (NPCs) with unique names, backstories, traits, motivations, and balanced statistical profiles. Manually creating deep, consistent characters from scratch is time-consuming for developers and creators.

## Scope of the Project
This project provides a clean, modular Python application (supporting both a text-based console menu and a standalone script) that automatically generates dynamic, randomized, and logically coherent NPCs. It connects occupations, personality traits, quotes, hobbies, secrets, and core stats (Bravery, Intelligence, Charisma, Luck, Creativity) using procedural generation rules.

## Target Users
* **Game Developers & Indie Creators:** Quickly populate game worlds with diverse characters.
* **Dungeon Masters & Tabletop RPG Players:** Instantly generate lore-friendly characters for campaigns.
* **Writers & Worldbuilders:** Overcome writer's block by discovering fresh character profiles and backstories.

## High-Level Features
* **Dual Console Options:** Run via structured menus (`main.py`) or a quick terminal script (`terminal_npc.py`).
* **Procedural Stat Balancing:** Automatically calculates and bounds statistics based on character traits and professions.
* **Rich Lore Generation:** Assigns unique quotes, likes/dislikes, personal goals, hobbies, and hidden secrets.
